## 禁止行为

- 禁止在本目录任何 markdown 文件中新增 backlog 条目

人工归档（Flag=✅ 迁 archive/）也走 GitHub Issues 关闭流程，不再在本目录回写。

- 只读引用：从代码 godoc / ADR / PR 描述链接到此处条目，仅作历史追溯
- 修正笔误 / 失效链接 / 格式错误（不改语义、不改状态）
