# Arch test

## 0. Template-PR-Split

framework + bulk migration + archtest enforcement 三维以上必拆 N 个 PR：第一个 PR = framework，最后一个 PR = archtest enforcement（enforcement 上线时所有站点已合规）。单 PR 多维捆绑会让 type-aware 边界多维 fail-open 缝隙同时暴露。

- PR1（framework）：新建 typed API + 单点 dogfood
- PR2（bulk migration）：已有站点批量迁移
- PR3（archtest enforcement）：拦裸调用形态 + 删旧 allowlist

## 1. Wave 1

### 1.1 TEST-POLLING-DETERMINISM typed marker

裸 `(require|assert).Eventually` + closure+done sentinel 轮询散落 ~339 站点 / ~70 文件，race CI flake（D500ms 踩穿为首例事故）。

**形态固定**：新建 `pkg/testutil/testwait/` —— `External(reason)` typed marker（保留真 wall-clock 等待）+ `Deterministic` 收纳 channel-as-condvar；一锅改造 339 站点；同 PR archtest 拦裸 `(require|assert).Eventually`；不 ratchet。

按 Template-Wave4-3PR 拆：

- **PR1 framework**（4-6h）：`pkg/testutil/testwait/` typed API + 单点 dogfood
- **PR2 bulk migration**（12-16h）：339 站点批量迁移
- **PR3 enforcement**（2-3h）：archtest 拦裸 `(require|assert).Eventually` + 拦 closure+done sentinel + 删旧 allowlist

合计 ~18-25h dev（一锅推估 24-32h）。每 PR review 面积 ≤ 单锅推一半，fail-open 缝隙按维度暴露。

**触发**：flake-density gate —— 第 2 次 race CI flake / 进入下一 AI-rebust 升级批 / 339 站点任一新增违反，任一即立项。

### 1.2 FINDFIRSTCHILD-TYPED-API-01

**形态固定**：`tools/archtest/internal/scanner` 加 `FindFirstChild[S any, N interface{ *S; ast.Node }](root ast.Node, pred func(N) bool) (N, bool)` typed find-first API（语义 = depth=1 + early-stop = typed function choice）；迁移 6 处 closure+done helper（`outbox_invariants_test.go` ×4 / `security_defaults_test.go::hasKey` / `contract_spec_clients_test.go` ×2）；删 sentinel 内联注释 + 删 ai-collab.md "closure+done family" 提及。

depth-1 部分已 ship。**单 PR + commit-level 分维度例外**（6 处 helper 总改动 < 200 LOC，review 面积可控）：framework + 一个 dogfood 先行 commit → 5 处迁移 + archtest 同 commit；3-4h dev / 1h review。

**触发**：第 7 处 closure+done sentinel helper 出现 / 进入下一 AI-rebust 升级批。

**残留（subtree 版，正交轴）**：`EachInSubtree` + 早返 sentinel（递归 find-first）仍散落约 50+ 站点，depth-1 的 `FindFirstChild` 不覆盖。立 `scanner.FindFirstInSubtree[N]` + 扩 USAGE-02 覆盖 EachInSubtree 早返子集。详 backlog `FINDFIRSTINSUBTREE-API-01`（cap-14-tooling.md，P2/Cx2，触发：第 N 处 EachInSubtree 早返 sentinel）。
